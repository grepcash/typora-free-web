# Web-Markdown-Editor

一款所见即所得 Markdown 网页编辑器，边写边排版，输入完成后自动渲染成最终样式。输入星号自动变成斜体；输入 # 自动渲染标题。格式化标记（\*、#、\[ 等）在光标离开时自动隐藏，再次聚焦可重新显示源码进行编辑。

行内标记：粗体、斜体、行内代码、删除线、==高亮文本==、下标 H2O、上标 E = mc^2^。尖括号包裹的裸链接自动识别为超链接：<https://prosemirror.net>。常规链接正常渲染：ProseMirror 指南、CommonMark 规范。Emoji 短代码实时解析：:books: :tada: :hourglass: :warning:

任务清单支持可视化交互勾选：

- 行内标记（斜体、粗体、代码、删除线、高亮、上下标）
- 自动链接与引用式链接
- 支持多列对齐表格
- 行内与块级数学公式（基于 KaTeX，支持 $...$、$$...$$、(T_{分组}=...)\\ 实时预览）

列表支持多层嵌套，内置 Typora 标志性三次回车梯阶退出：

1. 外层有序列表项

   - 嵌套无序列表项，内含 代码片段
   - 另一项，包含 粗体 文字

     1. 第三层嵌套有序项
2. 返回外层有序列表

> 引用块和段落一样完整支持全部行内标记。可在引用块内随意添加 ==高亮==、链接 或 代码，源码解析与导出可做到字节级无损往返。
>
> 在空引用行按下回车，即可退出引用块。

数学公式支持实时排版与交互编辑（基于 KaTeX 引擎，兼容 (formula)、$formula$、$$formula$$）： 计算机网络分组交换传输时间公式：(T_{分组}=\frac{x}{b}+(k-1)\frac{p}{b}+kd) 爱因斯坦质能方程：$E = mc^2$

块级公式： $$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

快捷键 ⌘/（Windows / Linux：Ctrl+/）随时切换渲染视图与原始 Markdown 源码视图。
